# leads-redirect

Redirectores HTML para vistas previas de landing pages de alojamientos cubanos.

Este repo se actualiza automáticamente por scripts del workspace `Paginas webs` (skill `dev-tunnel`). Cada subcarpeta `<slug>/` contiene 3 archivos HTML (`cozy.html`, `elegant.html`, `vibrant.html`) que redirigen a túneles cloudflared temporales durante el horario de visualización (9 AM – 4 PM hora de Cuba).

Fuera de horario los redirectores muestran un mensaje al lead invitando a volver en horario.
